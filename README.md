# Мэдээллийн нэгдсэн цонх (дашборд)

Хиймэл оюун ухаанд суурилсан ухаалаг программ хангамж (AI аналитик) болон видео удирдлагын системийн (VMS) мэдээллийг нэгтгэн харуулах дашбордын UI дизайн.

> Бүх тоо, камерын ID, байршил нь **жишээ өгөгдөл**.

## Бүтэц

`design/` хавтсанд Claude Design canvas-ын эх файлууд байна:

| Файл | Дэлгэц |
|---|---|
| `Main.dc.html` | 1. Нэгдсэн тойм — шүүлтүүр, KPI, газрын зураг, AI аналитик, иргэдийн эрчим |
| `Cameras.dc.html` | 2. Камерын төлөв ба ажиллагаа — ажиллаагүй хугацаа, uptime |
| `Event.dc.html` | 3. Онцгой арга хэмжээний горим — Наадам, ёслол, айлчлал |
| `Reports.dc.html` | 4. Цахим архив, харьцуулалт, олон форматын тайлан |
| `Access.dc.html` | 5. Хэрэглэгчийн эрхийн удирдлага, модуль/виджет өргөтгөл |
| `canvas.json` | Canvas-ын байршил, дэлгэцийн дараалал |

`.dc.html` файлууд нь Design editor-ын runtime (`support.js`)-ээр рендерлэгдэнэ. Хөтөч дээр шууд нээхэд бүрэн харагдахгүй.

| № | Шаардлага | Дэлгэц |
